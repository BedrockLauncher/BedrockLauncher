# Software Prerequisites
- Atleast Windows 10 `14393.0` or Windows 11 `22000.100`
- .NET Desktop Runtime 6.0.6 
  - https://dotnet.microsoft.com/en-us/download/dotnet/6.0
- A Microsoft account with Minecraft for Windows 10 owned
- Minecraft for Windows 10 beta sign-up using non-legacy Xbox Insider Hub

## Developer Mode 
Developer Mode should be enabled. This ensures that the app can be run without requiring admin permissions (for example, a child or less-privileged account can run instead of needing admin each time). To enable Windows Developer Mode:

1. Open Windows Settings
2. Go to **Privacy & security** → **For developers**
3. Turn on **Developer Mode**

If Developer Mode is not enabled, some operations may require running the launcher as administrator.
